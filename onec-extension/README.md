# Расширение конфигурации 1С (п. 8 ТЗ)

Поставка — **расширение конфигурации** без изменения типовой, цель MVP —
1С:Бухгалтерия 3.0, далее КА/ERP. Разрабатывается отдельной ролью
(1С-разработчик с опытом расширений и HTTP-сервисов).

## Объекты расширения

Справочники:
- «Криптоактивы»
- «Блокчейн-сети»
- «Кошельки/Адреса» (свои и контрагентов)
- «Источники котировок»

Документы:
- «Поступление цифровой валюты»
- «Выбытие цифровой валюты»
- «Переоценка цифровой валюты» (v1)

Регистры:
- партии ЦВ (для ФИФО)
- курсы
- привязки к договорам ВЭД (связь со стандартным справочником «Договоры»)

## Протокол обмена с коннектором

Фоновое задание синхронизации на стороне 1С раз в N минут:

1. `GET {connector}/api/v1/onec/documents?status=draft`
   — заголовок `X-Exchange-Token: <токен>`; ответ — пачка проектов документов
   с `idempotency_key` (сеть:хэш:log_index:тип).
2. По каждому проекту — найти существующий документ по `idempotency_key`
   (реквизит «КлючОбмена»); если нет — создать. Повторная выгрузка НЕ создаёт
   дублей.
3. `POST {connector}/api/v1/onec/documents/ack`
   — тело `[{"idempotency_key": "...", "onec_ref": "<GUID документа>"}]`.

Режимы (настройка): «проекты документов» — бухгалтер проводит вручную;
«авто-проведение» — документ проводится при создании.

## Мэппинг на план счетов

Счета учёта цифровой валюты, курсовых разниц и комиссий задаются при
внедрении под учётную политику клиента (преднастроенный дефолт поставляется,
финальный мэппинг утверждает главбух/аудитор клиента). Коннектор передаёт
суммы и аналитику, проводки формирует расширение.

## Стратегически

Пройти сертификацию «1С:Совместимо» — открывает канал продаж через
франчайзи 1С (план v1).
