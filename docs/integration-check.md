# Интеграционный прогон на живых сетях

Перед стыковкой с 1С и пилотом серверную часть нужно один раз прогнать
против реальных внешних API. Скрипт `scripts/integration_check.py` делает
это read-only: ничего не пишет, никуда не отправляет, приватные ключи
не нужны — только публичный адрес кошелька.

## Запуск (на машине с доступом в интернет)

```bash
git clone https://github.com/samoedov-web/1cconnector.git && cd 1cconnector
python3 -m venv .venv && . .venv/bin/activate
pip install -e .

python scripts/integration_check.py \
    --tron-address <ВАШ_АДРЕС_TRON> \
    --tron-api-key <КЛЮЧ_TRONGRID_ЕСЛИ_ЕСТЬ> \
    --eth-rpc https://<ваш-rpc-провайдер> --eth-address <0x...>
```

Все параметры необязательны — что не задано, будет помечено «⏭ пропущено».
Ключ TronGrid бесплатный (trongrid.io), без него работают публичные лимиты.

## Что проверяется

| Проверка | Что подтверждает |
|---|---|
| TRON latest_block | доступность источника, разбор высоты |
| TRON fetch_transfers | чтение TRC-20 USDT по адресу за 30 дней, пагинация |
| TRON get_transaction_block | реорг-проверка: блок совпадает с выдачей |
| TRON get_transaction_fee | догрузка комиссии (TRX) |
| TRON негатив | несуществующий хэш → None (не ошибка) |
| ETH latest_block / fetch_transfers | JSON-RPC, eth_getLogs кусками блоков |
| ЦБ РФ | курс USD/RUB на сегодня |
| CoinGecko | курс TRX/USD (оценка комиссий) |

## Сценарий с реальным переводом

1. Прогнать скрипт на своём адресе — все проверки зелёные.
2. Поднять коннектор (`docker compose up`), добавить этот адрес в панели
   (Кошельки → добавить, бэкфилл с даты ~месяц назад).
3. Сделать небольшой реальный перевод USDT на адрес.
4. Наблюдать в панели: транзакция появится со статусом `confirmed`,
   через ~1 минуту (19 блоков TRON) станет `final`, конвейер создаст
   партию ФИФО и проект «Поступления» — он виден в карточке транзакции
   и в очереди обмена (`GET /api/v1/onec/documents`).
5. Разобрать транзакцию в очереди (пока контрагент неизвестен — она
   попадёт в ручной разбор), распечатать акт по платежу.

Вывод скрипта и наблюдения из п. 4 пришлите разработчику — по ним
закрываются несоответствия реальных ответов API ожиданиям кода.

## Примечание про среду разработки

Из облачной среды Claude Code скрипт не выполняется: сетевая политика
разрешает только GitHub и реестры пакетов (api.trongrid.io, cbr.ru,
coingecko.com — 403 от прокси). Это ограничение среды, не кода.
