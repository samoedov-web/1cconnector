# Руководство для методолога (CryptoVED v2.1)

Этот документ предназначен для проверки соответствия системы требованиям законодательства РФ и внутренним регламентам.

## 1. Проверка регуляторных правил
Файл: `src/connector/config.py` (или через API `/regulatory-versions`)
- [ ] Пороги AML-скрининга (0–30, 31–70, 71–100) соответствуют 115-ФЗ.
- [ ] Таймер обнаружения транзакции (30 мин) корректен.
- [ ] Срок одобрения платежа (48 ч) соответствует регламенту.
- [ ] Порог обязательного контроля (10 млн ₽) настроен верно.

## 2. Проверка налогового учета
Файл: `src/connector/reports/tax_registry.py`
- [ ] Метод ФИФО реализован согласно ст. 282.3 НК РФ.
- [ ] Переоценка активов не влияет на налоговую базу до выбытия.
- [ ] Курс ЦБ используется корректно (на дату операции/переоценки).

## 3. Проверка отчетных форм
Файл: `src/connector/reports/regulatory.py`
- [ ] Форма уведомления ФНС о счетах актуальна (2026 г.).
- [ ] Справка о подтверждающих документах (181-И) верна.
- [ ] Реестр операций для внутреннего аудита полон.

## 4. Сценарии ручного разбора
Файл: `src/connector/custody/reconciliation.py`
- [ ] Расхождения "нет в выписке" / "нет в цепочке" трактуются верно.
- [ ] Агрегированные записи выписки обрабатываются корректно.
- [ ] Дубликаты строк выписки flagged на ручную проверку.

## 5. Acceptance-тесты
Запустите: `pytest tests/test_acceptance_whitepaper.py -v`
Все тесты должны пройти (PASS). Любой FAIL — повод для пересмотра кода или требований.
