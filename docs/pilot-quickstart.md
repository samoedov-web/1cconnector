# Пошаговый запуск пилота (для не-разработчика)

Инструкция «с нуля до реального перевода» на обычном компьютере
Windows или Mac. Из установок нужен только Docker Desktop.

## Шаг 1. Установить Docker Desktop

1. Скачайте: https://www.docker.com/products/docker-desktop/
   (кнопка Download, выберите свою систему).
2. Установите как обычную программу. На Windows установщик может
   попросить включить WSL2 и перезагрузиться — соглашайтесь.
3. Запустите Docker Desktop и дождитесь, пока значок кита в трее
   перестанет мигать (статус Running / зелёный).

## Шаг 2. Скачать проект

1. Откройте ссылку:
   https://github.com/samoedov-web/1cconnector/archive/refs/heads/claude/new-session-9f4zev.zip
2. Распакуйте архив в удобную папку, например `C:\connector`
   (Mac: `~/connector`).

## Шаг 3. Заполнить настройки

1. В папке проекта найдите файл `.env.example`.
   *Windows: если расширений не видно — в Проводнике вкладка «Вид» →
   галочка «Расширения имён файлов».*
2. Скопируйте его и переименуйте копию в `.env` (точка в начале, без
   `.example`).
3. Откройте `.env` Блокнотом и замените три значения:
   - `POSTGRES_PASSWORD=` — любой пароль (латиница/цифры);
   - `CONNECTOR_SECRET_KEY=` — длинная случайная строка, 30+ символов;
   - `CONNECTOR_ADMIN_PASSWORD=` — пароль, которым будете входить в панель.
4. Сохраните файл. Остальное не трогайте — источник данных TRON уже
   прописан.

## Шаг 4. Запустить

1. Откройте командную строку **в папке проекта**:
   - Windows: откройте папку в Проводнике, щёлкните в адресную строку,
     напишите `cmd` и нажмите Enter;
   - Mac: откройте Terminal и выполните `cd ~/connector`.
2. Выполните команду:

   ```
   docker compose up -d --build
   ```

3. Первый запуск скачивает и собирает всё необходимое — 5–10 минут.
   Готово, когда команда завершится без красных ошибок.

## Шаг 5. Войти в панель

Откройте в браузере http://localhost:8000 — увидите экран входа.
Логин `admin`, пароль — из `CONNECTOR_ADMIN_PASSWORD`.

На экране «Мониторинг» должны быть сети TRON и Ethereum (создаются
автоматически) и лицензия «Демо» (для пилота этого достаточно:
1 юрлицо, 1 кошелёк).

## Шаг 6. Проверка связи с внешним миром

В той же командной строке (подставьте свой адрес TRON):

```
docker compose run --rm api python scripts/integration_check.py --tron-address ВАШ_АДРЕС
```

Скрипт ничего не переводит и не требует ключей — только читает
публичные данные. Скопируйте весь вывод (или скриншот) — его нужно
прислать разработчику.

## Шаг 7. Добавить кошелёк и сделать перевод

1. В панели: **Кошельки** → сеть `tron` → вставьте ваш адрес →
   «Бэкфилл с даты» поставьте примерно месяц назад → Добавить.
2. Сделайте небольшой реальный перевод USDT (достаточно 1–2 USDT)
   на этот адрес с любой биржи или кошелька.
3. Подождите 2–3 минуты и откройте экран **Транзакции**:
   - появится строка со статусом `confirmed`, затем `final`
     (TRON финализируется за ~1 минуту);
   - если по адресу были операции за последний месяц — подтянутся и они;
   - в **Очереди разбора** появится строка (отправитель системе ещё
     не знаком) — можно попробовать «Разобрать»: создать контрагента
     на экране «Контрагенты», привязать и поставить галочку
     «запомнить адрес».
4. Откройте карточку транзакции — там будут рублёвая оценка, журнал
   неизменяемости и кнопка «Акт (печать)».

## Шаг 8. Что прислать разработчику

1. Вывод команды из шага 6.
2. Скриншот экрана «Транзакции» и карточки транзакции.
3. Если что-то не появилось или видна ошибка — выполните:

   ```
   docker compose logs indexer > logs.txt
   docker compose logs api >> logs.txt
   ```

   и пришлите файл `logs.txt` из папки проекта.

## Полезное

- Остановить: `docker compose down` (данные сохраняются).
- Запустить снова: `docker compose up -d`.
- Если транзакции не появляются долго: публичные лимиты TronGrid могли
  сработать — зарегистрируйте бесплатный ключ на https://www.trongrid.io,
  впишите его в `.env` в строку `TRON_SOURCE_1_API_KEY=` и выполните
  `docker compose up -d` ещё раз.
