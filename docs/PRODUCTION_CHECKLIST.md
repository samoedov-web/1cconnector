# Чек-лист перед выходом в Production

## Инфраструктура
- [ ] PostgreSQL настроен (режим репликации, бэкапы каждый час).
- [ ] Redis развернут для кеширования курсов и сессий.
- [ ] Блокчейн-ноды/провайдеры доступны (HTTP 200, latency < 500ms).
- [ ] 1С:Предприятие доступно по HTTP/API.

## Конфигурация
- [ ] Переменные окружения установлены (`DATABASE_URL`, `REDIS_URL`, `BLOCKCHAIN_RPC_...`).
- [ ] Секреты (API keys) загружены в vault, не захардкожены.
- [ ] Таймауты соединений настроены (DB, RPC, 1C).

## Данные
- [ ] Миграции применены (`alembic current` показывает последнюю).
- [ ] Фикстуры загружены (справочники сетей, активов, контрагентов).
- [ ] Начальные балансы выверены (если был бэкап со старой системы).

## Мониторинг
- [ ] Health-check эндпоинт `/health` возвращает 200 OK.
- [ ] Алерты настроены (отставание индексации > 10 блоков, ошибки AML API).
- [ ] Логирование включено (уровень INFO, формат JSON).

## Безопасность
- [ ] Доступ к БД только из подсети приложения.
- [ ] HTTPS включен для API и Web UI.
- [ ] Роли пользователей розданы (Admin, Operator, Compliance, Auditor).
- [ ] Приватные ключи отсутствуют в системе (проверка grep).

## Тесты
- [ ] `pytest` проходит без ошибок (0 failed).
- [ ] Нагрузочное тестирование выполнено (целевая RPS достигнута).
- [ ] Disaster Recovery протестирован (восстановление из бэкапа < 4 часов).

## Документация
- [ ] README актуален.
- [ ] Инструкция для оператора распечатана/доступна.
- [ ] Контакты экстренной поддержки указаны.
