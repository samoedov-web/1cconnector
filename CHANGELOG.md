# Changelog

## [2.1.0] - 2026-09-18

### Added
- **Stage 1:** Депозитарный контур (сверка блокчейн ↔ выписка, режимы off/shadow/active).
- **Stage 2:** Жизненный цикл операций (Operation Lifecycle, граф переходов).
- **Stage 3:** Адаптеры реестров (ЦБ) и рисков эмитента (USDT/USDC).
- **Stage 4:** Evidence Vault (неизменяемое хранение доказательств, SHA-256).
- **Stage 5:** Compliance Approval Gate (автоматический шлюз AML+Registry+Issuer).
- **Stage 6:** Web UI (компоненты Reconciliation.jsx, Aml.jsx) + Acceptance Tests.
- **Stage 7:** Интеграция с 1С (обмен документами) + Налоговый регистр (ФИФО).
- **Stage 8:** Регуляторная отчетность (ФНС, ЦБ, Валютный контроль).
- **Stage 9:** Production Hardening (мониторинг, алерты, фикстуры).
- **Stage 10:** Полная документация (README,_guide для методолога, чек-листы).

### Security
- Подтвержден Read-Only статус: отсутствие приватных ключей и функций подписания.
- Внедрено неизменяемое логирование (AuditLog).

### Changed
- Обновлены модели данных для соответствия Whitepaper v2.1.
- Унифицированы миграции Alembic.

### Fixed
- Исправлены проблемы дедупликации транзакций.
- Устранены расхождения в методах расчета налоговой базы.
